# Predictive modeling w/ model comparison

## Project Overview
This project compares multiple predictive models on a regression problem. I used a public dataset to predict housing prices then evaluate which model performs best.

## Models Compared
 Linear Regression (baseline)
 Random Forest
 XGBoost

## Key Metrics
 RMSE
 R-squared
 MAE

## Skills Demonstrated
 Feature engineering
 Model comparison
 Hyperparameter tuning
 Evaluation metrics
 Visualization

## How to Run
1. `pip install -r requirements.txt`
2. `python data_prep.py`
3. `jupyter notebook`
4. Open `notebooks/model_comparison.ipynb`
